# Il mio Orto

App per la gestione dell'orto in cassoni: schede colture, calendario di semina per zona (Nord / Centro / Sud e isole), rotazione per cassone e progetto su griglia con vista isometrica.

- `app/` – la web app (PWA statica, nessun server). Viene pubblicata su GitHub Pages a ogni push su `main`.
- `app/data/colture.js` – database delle colture (dati indicativi).
- `serve.ps1` – server locale per provarla: `http://localhost:8950`.
